# Rust_ESP32_STD
Laboratorio personal de proyectos, ejemplos y diagramas realizados con mi ESP32 cuya base principal es Rust orientado a su versión STD. Abarcando desde lo más simple hasta proyectos ligeros de IoT. El propósito de este repo es servir como guía de cómo interactúa Rust con el ESP32 (en modo std), utilizando el modelo S3.
